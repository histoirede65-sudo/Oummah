OUMMAH — Wasil parcours Premium v2

Ce correctif est cumulatif : il contient le moteur des parcours progressifs et leur verrouillage Premium.

1. Copiez le dossier src dans la racine du projet en conservant les chemins.
2. Dans Supabase, exécutez la migration :
   src/supabase/migrations/202607220001_premium_entitlements.sql
3. Sans ligne d’abonnement active, l’utilisateur reste en version gratuite.

Test manuel temporaire d’un compte Premium dans l’éditeur SQL Supabase :

insert into public.premium_entitlements (
  user_id,
  status,
  source,
  current_period_end
)
values (
  'REMPLACER_PAR_UUID_UTILISATEUR',
  'active',
  'manual',
  now() + interval '30 days'
)
on conflict (user_id) do update set
  status = excluded.status,
  source = excluded.source,
  current_period_end = excluded.current_period_end,
  updated_at = now();
