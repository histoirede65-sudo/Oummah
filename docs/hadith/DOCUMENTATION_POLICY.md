# Charte documentaire officielle du corpus Hadith

**Statut : référence officielle du projet OUMMAH**

Cette charte définit les règles applicables à toute donnée religieuse intégrée au corpus Hadith d’OUMMAH.

## 1. Philosophie

OUMMAH n’est pas un éditeur religieux. OUMMAH est un agrégateur documentaire.

Les textes religieux sont conservés tels qu’ils proviennent de leurs sources. Ils ne sont jamais réécrits, corrigés ou améliorés manuellement.

Les traductions ne sont jamais générées par IA, par Codex, par ChatGPT ou par un système équivalent. Les explications et les enseignements ne sont jamais inventés.

Les explications officielles ne remplacent jamais les sources primaires. Les analyses produites par Wasil sont toujours distinguées des contenus officiels.

## 2. Texte arabe

Tout texte arabe intégré doit disposer, lorsque l’information est disponible, de :

- l’édition précisément identifiée ;
- la provenance connue ;
- la version du corpus ;
- la référence source ;
- la licence ou l’autorisation applicable ;
- la date d’import.

Le texte arabe ne doit subir aucune modification, correction manuelle, suppression, ajout ou normalisation silencieuse. Toute différence entre deux éditions doit être conservée comme une différence documentaire explicite, jamais fusionnée sans justification.

## 3. Traductions

Chaque traduction doit être documentée par :

- son auteur ;
- son éditeur ou organisme responsable ;
- sa source ;
- son édition ;
- sa version ;
- sa licence ou son autorisation ;
- sa date d’import, si elle est connue ;
- sa référence source.

Sont interdites :

- les traductions générées par IA ;
- les traductions produites par Codex ;
- les traductions produites par ChatGPT ;
- les traductions maison non publiées par une source identifiée ;
- toute modification silencieuse d’une traduction existante.

Une traduction absente d’une source validée reste absente du corpus. Elle ne doit pas être remplacée par une traduction automatique ou improvisée.

## 4. Explications

Les explications suivent les mêmes règles de traçabilité que les traductions.

Chaque explication doit comporter, lorsque l’information est disponible :

- son auteur ;
- l’organisme ou l’éditeur ;
- son édition ;
- sa provenance ;
- sa version ;
- sa licence ou son autorisation ;
- sa référence source ;
- sa date d’import.

Une explication externe ne doit jamais être présentée comme une explication originale d’OUMMAH. Une explication générée par IA ne peut pas être publiée comme contenu officiel.

## 5. Enseignements

Les enseignements doivent provenir d’une source identifiée et autorisée.

Ils doivent conserver :

- leur ordre d’origine ;
- leur texte exact ;
- leur provenance propre ;
- leur version ;
- leur licence ou autorisation ;
- leur référence source.

Les enseignements ne doivent jamais être inventés, complétés ou reformulés pour remplir une section vide. Si aucune source validée ne fournit d’enseignements, la section reste vide.

## 6. Wasil

Wasil peut expliquer, reformuler, résumer, comparer et enseigner dans un contexte pédagogique.

Cependant, les textes affichés comme officiels ne proviennent jamais de Wasil. Toute sortie de Wasil doit être identifiée comme analyse, reformulation ou contenu pédagogique généré à la demande.

La séparation documentaire est la suivante :

```text
Texte officiel
        ↓
Traduction officielle
        ↓
Explication officielle
        ↓
Analyse pédagogique Wasil
```

Wasil ne doit jamais être présenté comme l’auteur d’un texte source, d’une traduction officielle, d’une explication publiée ou d’un enseignement provenant d’un éditeur.

## 7. Traçabilité

Chaque donnée intégrée doit pouvoir être reliée à :

- sa source ;
- son édition ;
- sa version ;
- sa licence ou son autorisation ;
- sa référence source ;
- sa date d’import ;
- son identifiant source stable, lorsqu’il existe ;
- son statut de vérification.

La provenance doit être conservée séparément pour le texte arabe, la traduction, l’explication et chaque enseignement lorsque leurs sources diffèrent.

Un texte ne doit jamais servir seul de clé d’identité. Les identifiants, références et numéros structurés doivent être privilégiés.

## 8. Mise à jour

Lorsqu’une nouvelle version officielle apparaît, elle doit être enregistrée comme une nouvelle version documentaire.

Une ancienne version ne doit jamais être remplacée silencieusement. Il faut conserver :

- l’ancienne version ;
- la nouvelle version ;
- leur provenance respective ;
- la date de chaque import ;
- les différences documentées, lorsqu’elles existent ;
- le statut de la version active.

Une mise à jour doit être validée avant publication. L’attribution et les obligations de licence doivent être réexaminées pour chaque nouvelle version.

## 9. Contrôle qualité

Avant tout import, la checklist suivante est obligatoire :

- [ ] provenance identifiée ;
- [ ] licence ou autorisation vérifiée ;
- [ ] édition identifiée ;
- [ ] intégrité du fichier et des contenus contrôlée ;
- [ ] attribution définie ;
- [ ] numérotation vérifiée ;
- [ ] version enregistrée ;
- [ ] cohérence entre collection, livre, chapitre et hadith vérifiée ;
- [ ] cohérence entre texte arabe et traduction contrôlée ;
- [ ] contrôle manuel effectué ;
- [ ] contenus facultatifs confirmés présents ou absents ;
- [ ] absence de contenu généré ou inventé confirmée.

Tout échec de cette checklist bloque l’import jusqu’à résolution ou décision documentaire explicite.

## 10. Ce qui est interdit

Il est interdit de :

- ❌ produire une traduction par IA ;
- ❌ publier une explication générée par IA comme explication officielle ;
- ❌ publier des enseignements générés ou inventés ;
- ❌ mélanger deux éditions sans le documenter ;
- ❌ supprimer une partie du texte ;
- ❌ modifier le texte arabe ;
- ❌ modifier une traduction ou une explication source ;
- ❌ changer la numérotation source ;
- ❌ perdre ou omettre la provenance ;
- ❌ importer sans licence ou autorisation identifiée ;
- ❌ présenter une analyse Wasil comme une source officielle ;
- ❌ remplacer silencieusement une version antérieure ;
- ❌ combler un contenu manquant par une invention.

## 11. Engagement OUMMAH

OUMMAH s’engage à préserver fidèlement le patrimoine islamique en respectant l’intégrité des textes, la provenance des éditions, les droits des auteurs et les conditions des éditeurs.

OUMMAH s’engage également à permettre un apprentissage moderne grâce à Wasil, tout en maintenant une séparation claire entre le contenu officiel et le contenu pédagogique.

Cette séparation est une exigence documentaire permanente : le lecteur doit pouvoir distinguer ce qui provient d’une source publiée, ce qui constitue une traduction ou une explication attribuée, et ce qui relève d’une analyse pédagogique générée par Wasil.

Toute évolution du corpus Hadith doit respecter cette charte. En cas de doute sur une source, une licence, une édition, une version ou une modification, l’intégration est suspendue jusqu’à vérification.
