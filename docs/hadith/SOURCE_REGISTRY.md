# Registre officiel des sources Hadith

**Statut : registre documentaire officiel du module Hadith d’OUMMAH**

## 1. Introduction

Ce registre centralise les sources documentaires utilisées ou envisagées par OUMMAH pour le module Hadith.

Aucune donnée religieuse ne peut être importée dans OUMMAH sans qu’une fiche de source correspondante existe dans ce registre et que son statut documentaire autorise explicitement son utilisation.

Une source doit pouvoir être identifiée, vérifiée, attribuée et auditée. La présence d’une source dans ce registre ne signifie pas qu’elle est validée pour l’import.

## 4. Règles de validation

Une source ne peut passer au statut `Validée` que si les éléments suivants sont connus et documentés :

- [ ] provenance ;
- [ ] organisme ou auteur ;
- [ ] édition ;
- [ ] version ;
- [ ] licence ou autorisation ;
- [ ] attribution ;
- [ ] intégrité du contenu ;
- [ ] compatibilité avec la [Charte documentaire officielle du corpus Hadith](DOCUMENTATION_POLICY.md) ;
- [ ] compatibilité technique avec le corpus OUMMAH ;
- [ ] conditions d’utilisation mobile et de redistribution ;
- [ ] conditions d’utilisation commerciale, si concerné ;
- [ ] méthode de mise à jour ;
- [ ] responsable de validation identifié.

Une source en étude ou en validation ne doit pas être utilisée pour un import réel.

## 5. Règles de mise à jour

Lorsqu’une nouvelle version d’une source apparaît :

- l’ancienne version reste documentée ;
- la nouvelle reçoit une nouvelle fiche ou une nouvelle version explicitement identifiée ;
- la date et le responsable de la validation sont enregistrés ;
- les changements importants sont décrits ;
- aucune mise à jour silencieuse n’est autorisée ;
- l’attribution et la licence sont revérifiées.

Une nouvelle version ne remplace pas automatiquement une version antérieure dans les données déjà importées.

## 6. Sources rejetées

Les sources rejetées doivent rester documentées afin d’éviter leur réévaluation répétée ou leur utilisation accidentelle.

## 8. Engagement

Ce registre garantit la traçabilité documentaire complète du corpus Hadith d’OUMMAH. Il permet de justifier l’origine, l’édition, la version, la licence et les conditions d’utilisation de chaque contenu affiché dans l’application.

OUMMAH s’engage à maintenir ce registre avant toute intégration de nouvelle source, à conserver l’historique des versions et à ne jamais présenter comme validée une source dont la provenance ou les conditions de réutilisation restent incertaines.
